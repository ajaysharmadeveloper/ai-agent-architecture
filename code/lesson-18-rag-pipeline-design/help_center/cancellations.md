# Cancellations

## Cancelling before the order ships

You can cancel any order for free while its status is still Placed or Packed. Open the order and tap Cancel. For a prepaid order, the refund is started at once and reaches you within 2 working days, which is faster than a normal return because nothing has to travel back to us. For a cash on delivery order nothing was charged, so there is nothing to refund.

## Cancelling after the order ships

Once the status says shipped, the Cancel button goes away. The package is already with the courier and we can't call it back. You can refuse it at the door, or accept it and start a return. The rules for both are on the Returns and refunds page.

## Cancelling part of an order

If an order has more than one item, you can cancel a single item before it ships. The rest of the order continues as normal. If removing the item takes the order below the free shipping limit, the shipping fee is added to what remains, and we show you the new total before you confirm.
