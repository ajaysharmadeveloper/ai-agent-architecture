# Exchanges

## Size exchange for shoes

If your shoes don't fit, you can exchange them for another size within 15 days of delivery. The shoes must be unworn outside, with the tags on and the box intact. We pick up the old pair and deliver the new one in the same visit where our courier supports it. Each item can be exchanged once.

## Price differences

If the new size or colour costs more, you pay the difference before the exchange is confirmed. If it costs less, we refund the difference to your original payment method after the old pair is picked up. An exchange never resets the 30 day refund window. That window still counts from the first delivery.

## What can't be exchanged

Headphones and water bottles can't be exchanged for a different model or colour. If one of them is faulty, use the warranty process and we will replace it with the same model. Final sale items, such as earbuds with a broken seal, can't be exchanged either.
